# DESIGN.md — Дизайн-контракт пользовательского интерфейса dsh-usage-guard

## 1. User Surfaces (Пользовательские поверхности)

Плагин предоставляет единую поверхность настроек в Web UI DeepSeek Harness:

### Основной слот: `settings.plugin.item`
- **Расположение:** вкладка «Настройки → Плагины → Настройки плагинов».
- **Ключ слота (`entryKey`):** `dsh-usage-guard` (строго равен пространству настроек в Cordis).
- **Поведение:** свёрнутая по умолчанию карточка с заголовком, кратким описанием и бейджем текущего режима работы.
- **Интерактивные поля:**
  1. `repair` (checkbox): автоматическое исправление повреждённых счётчиков токенов (подстановка синонима или безопасного нуля).
  2. `report` (checkbox): вывод диагностических предупреждений в системную консоль при обнаружении битой порции.

### Запасной слот (Fallback): `settings.section`
- **Условие включения:** если в используемой сборке ядра DSH отсутствует слот `settings.plugin.item` (таймаут 3 секунды).
- **Расположение:** боковой список вкладок настроек ядра.
- **ID секции:** `@goodandready/dsh-usage-guard`.

## 2. Components and States (Компоненты и состояния)

### Иерархия карточки
```
.ug-card
├── button.ug-head (aria-expanded, click toggle)
│   ├── span.ug-title ("Usage Guard" / "Защита истории токенов")
│   ├── span.ug-sub ("Token-usage sanitizer & session crash protection")
│   ├── span.ug-badge (ACTIVE [зелёный] / REPORT ONLY [жёлтый])
│   └── Chevron (.ug-chev, .ug-chev-open)
└── div.ug-body (рендерится при раскрытии)
    ├── loading state (если snapshot.status === 'loading')
    ├── fields list (если snapshot.status === 'ready')
    │   ├── field repair + description
    │   └── field report + description
    └── div.ug-foot
        ├── status msg (Saved / ошибки записи)
        └── button.ug-save ("Save" / "Сохранить")
```

### Состояния данных
1. **Loading (`snap.status === 'loading'`)**:
   Отображается лаконичный текстовый индикатор загрузки, поля формы скрыты до получения снимка от хоста.
2. **Ready (`snap.status === 'ready'`)**:
   Чтение актуальных значений `repair` и `report` из снимка `scope.getSnapshot()`. Чекбоксы интерактивны.
3. **Saving (`saving === true`)**:
   Кнопка «Сохранить» заблокирована (`disabled`), текст меняется на «Сохранение…».
4. **Unavailable (`snap.status === 'unavailable'`)**:
   Сообщение о недоступности пространства настроек хоста.
5. **Error**:
   При сбое записи одного из полей выводится поименный список ошибок рядом с кнопкой сохранения без падения карточки.

## 3. Токены темы и доступность

- **Цвета и стили:** используются строго CSS-переменные темы DSH:
  - Фоновые слои: `var(--dsw-alias-bg-layer-3)`.
  - Границы: `var(--dsw-alias-border-l2)`.
  - Текст: `var(--dsw-alias-label-primary)`, `var(--dsw-alias-label-secondary)`, `var(--dsw-alias-label-tertiary)`.
  - Бейджи: `var(--dsw-alias-color-success)`, `var(--dsw-alias-color-warning)`.
- **Изоляция:** все CSS-правила имеют уникальный префикс `.ug-*`.
- **Доступность (A11y):**
  - Шапка карточки — нативный `<button>` с клавиатурным фокусом и атрибутом `aria-expanded`.
  - Чекбоксы обёрнуты в `<label>` с понятными текстовыми подписями.

## 4. Locked Design Decisions

* **2026-09-05:** Карточка настроек регистрируется строго в `settings.plugin.item` с ключом `dsh-usage-guard` (соответствует пространству настроек). Свой раздел верхнего уровня запрещён в штатном режиме во избежание захламления бокового меню.
* **2026-09-05:** Бейдж статуса в шапке наглядно показывает текущий режим защиты (`ACTIVE` при `repair === true` или `REPORT ONLY` при отключённом автоисправлении) без необходимости раскрывать карточку.
