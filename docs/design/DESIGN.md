# DESIGN.md — Дизайн-контракт пользовательского интерфейса dsh-usage-guard

## 1. User Surfaces (Пользовательские поверхности)

Плагин предоставляет единую поверхность настроек в Web UI DeepSeek Harness:

### Основной слот: `settings.plugin.item`
- **Расположение:** вкладка «Настройки → Плагины → Настройки плагинов».
- **Ключ слота (`entryKey`):** `dsh-usage-guard` (строго равен пространству настроек в Cordis).
- **Поведение:** свёрнутая по умолчанию карточка с заголовком, кратким описанием и бейджем текущего режима работы.
- **Интерактивные поля:**
  1. `repair` (checkbox, id: `ug-repair-toggle`): автоматическое исправление повреждённых счётчиков токенов (подстановка синонима или безопасного нуля).
  2. `report` (checkbox, id: `ug-report-toggle`): вывод диагностических предупреждений в системную консоль при обнаружении битой порции.

### Запасной слот (Fallback): `settings.section`
- **Условие включения:** если в используемой сборке ядра DSH отсутствует слот `settings.plugin.item` (таймаут 3 секунды).
- **Расположение:** боковой список вкладок настроек ядра.
- **ID секции:** `@goodandready/dsh-usage-guard`.

## 2. Components and States (Компоненты и состояния)

### Иерархия карточки
```
.ug-card
├── button.ug-head (aria-expanded, click toggle)
│   ├── span.ug-title ("Usage Guard" / "Защита истории токенов")
│   ├── span.ug-sub ("Token-usage sanitizer & session crash protection")
│   ├── span.ug-badge (ACTIVE [зелёный] / REPORT ONLY [жёлтый])
│   └── Chevron (.ug-chev, .ug-chev-open, aria-hidden="true")
└── div.ug-body (рендерится при раскрытии)
    ├── loading state (если snapshot.status === 'loading')
    ├── unavailable state (если snapshot.status === 'unavailable')
    ├── fields list (если snapshot.status === 'ready')
    │   ├── field repair (label + input#ug-repair-toggle + description)
    │   └── field report (label + input#ug-report-toggle + description)
    └── div.ug-foot
        ├── status msg (автоматически исчезает через 3 сек, сбрасывается при драфте)
        └── button.ug-save ("Save" / "Сохранить", disabled при saving)
```

### Состояния данных
1. **Loading (`snap.status === 'loading'`)**:
   Отображается лаконичный текстовый индикатор загрузки, поля формы скрыты до получения снимка от хоста.
2. **Ready (`snap.status === 'ready'`)**:
   Чтение актуальных значений `repair` и `report` из снимка `scope.getSnapshot()`. Чекбоксы интерактивны. При фоновом изменении настроек (в `settings.yaml` или другой вкладке) драфт плавно синхронизируется, если пользователь не вносит правки в данный момент (`!isDirty`).
3. **Saving (`saving === true`)**:
   Кнопка «Сохранить» заблокирована (`disabled`), текст меняется на «Сохранение…».
4. **Saved Feedback**:
   Текст «Сохранено» / «Saved» отображается зелёным/нейтральным статусом и автоматически исчезает через 3 секунды, либо мгновенно сбрасывается при любом последующем переключении чекбоксов.
5. **Unavailable (`snap.status === 'unavailable'`)**:
   Сообщение о недоступности пространства настроек хоста.
6. **Error**:
   При сбое записи выводится точный список ошибок рядом с кнопкой сохранения без падения карточки.

## 3. Токены темы и доступность

- **Цвета и стили:** используются строго CSS-переменные темы DSH:
  - Фоновые слои: `var(--dsw-alias-bg-layer-3)`.
  - Границы: `var(--dsw-alias-border-l2)`.
  - Текст: `var(--dsw-alias-label-primary)`, `var(--dsw-alias-label-secondary)`, `var(--dsw-alias-label-tertiary)`.
  - Бейджи: `var(--dsw-alias-color-success)`, `var(--dsw-alias-color-warning)`.
- **Изоляция:** все CSS-правила имеют уникальный префикс `.ug-*`.
- **Доступность (A11y):**
  - Шапка карточки — нативный `<button>` с клавиатурным фокусом и атрибутом `aria-expanded`.
  - Иконка шеврона помечена `aria-hidden="true"`.
  - Чекбоксы имеют семантические `id` (`ug-repair-toggle`, `ug-report-toggle`) и сопряжены с `<label htmlFor="...">`.

## 4. Locked Design Decisions

* **2026-09-08 (v0.1.3):** Автоматическое исчезновение обратной связи сохранения через 3 секунды и мгновенный сброс текста при редактировании чекбоксов для исключения ложной иллюзии сохранённого драфта.
* **2026-09-08 (v0.1.3):** Фоновые обновления настроек ядра синхронизируются с карточкой, если пользователь не держит локально изменённый несохранённый драфт (`isDirtyRef`).
* **2026-09-05 (v0.1.2):** Карточка настроек регистрируется строго в `settings.plugin.item` с ключом `dsh-usage-guard`.
* **2026-09-05 (v0.1.2):** Бейдж статуса в шапке наглядно показывает текущий режим защиты (`ACTIVE` при `repair === true` или `REPORT ONLY` при отключённом автоисправлении).
